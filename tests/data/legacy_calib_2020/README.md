# 旧システム(2020 年)のキャリブボードの実データ

旧システムの `AgInkBeta/CalibBoard/N.png`(N = 1〜13、1376×1024)と、そのとき保存されたホモグラフィ `AgInkBeta/Homography/N.csv` から切り出した、小さな正解データです。

| ファイル | 内容 |
|---|---|
| `centers_N.csv` | 画像から検出した 77 個の黒円の中心 [pixel]。`BoardLayout::legacy2020()` の並び(行優先)。OpenCV の円格子検出で得て、ボードの X 軸が画像の右向き ±90° 以内になる向きを選んだもの |
| `H_saved_N.csv` | 旧システムが保存したホモグラフィ(3×3、ボード座標 mm → 画像 pixel) |

ボードは 11×7 = 77 個、間隔 30×40 mm、紙 467×317 mm(旧 Paperparam.h の 2020 年の値)。
ボードの回転は N = 1 で +35°、N = 13 で -52°(約 7° ずつ)で、向きを決める規則の検証に使える。

画像そのもの(各 2.8 MB)はリポジトリに入れていない。画像を使う検証は、環境変数 `BRDF_LEGACY_CALIB_DIR` に旧システムの `AgInkBeta` フォルダを指定して、`brdf_tests "[.full]"` で実行する。
