# テスト用の照合データ

旧システムが出力した角度表 `D:\Data\AngleTable\out1〜3.csv`(各 117,649 行)から、
500 行ごとに切り出したものです。新しい順運動学・角度計算が旧システムと一致することの確認に使います。

| ファイル | 左アーム(光源)の姿勢 [deg] | 元ファイル |
|---|---|---|
| `angle_table_out1_sample.csv` | (65, 0, 90, 0, 0, 0) | out1.csv |
| `angle_table_out2_sample.csv` | (60, 0, 90, 0, 0, 0) | out2.csv |
| `angle_table_out3_sample.csv` | (50, 0, 90, 0, 0, 0) | out3.csv |

列: `RJ1..RJ6`(右アームの関節角 [deg])、`theta_in, phi_in, theta_out, phi_out`(角度 [deg])。

## 当時の装置パラメータ

このデータは 2023-08 に生成されたもので、データから逆算した結果、次の値で作られています。

- カメラ(分光放射計)の位置: **(1272, 710, 554) mm**
  (旧ヘッダ `SpectrometerParam.h` の現在値 (1136, 728, 560) とは違う。測定日ごとに手で書き換えていたため)
- 試料面オフセット 6 mm、光源オフセット (-30, 108, 0) mm、右アーム土台 (0, 945, 0) mm は現在値と同じ
- 角度は、アーム先端の座標系(`RigGeometry::tipFrame`)を基準に測られている
  (試料点ごとの角度で使われる紙の座標系 `paperFrame` とは φ が 90° ずれる)

有効桁は 6 桁(CSV 出力の丸め)なので、照合の許容誤差は 0.002° にしてあります。
